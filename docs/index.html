The problem

You run several coding agents at once — Claude Code, Cursor, Codex. You ask session A to “copy the result”. Before you paste, session B writes to the clipboard too. The system clipboard is one global slot, last writer wins: you paste the wrong thing into the wrong thread.

without clipslot                      with clipslot

session A ──┐                         session A ──▶ slot repo-a@main
session B ──┼──▶ [ clipboard ]        session B ──▶ slot repo-b@fix
session C ──┘    last writer wins     session C ──▶ slot repo-c@main
                                                        │
you: Cmd+V  🎲                        you: pick a slot ──▶ [ clipboard ] ──▶ Cmd+V ✓

Three layers of defense

01 · SLOTS

Agents write to slots

With the bundled skill/rules, agents run clipslot copy instead of pbcopy. Content lands in a named slot (repo@branch) — nothing touches the clipboard, so sessions can’t clobber each other.

02 · LOAD

You arm the clipboard last

Right before pasting: clipslot load (fzf picker), load --gui (native macOS dialog), load -1 (latest), or the Raycast extension — Enter pastes straight into the app you came from.

03 · WATCH

History catches everything else

clipslot watch install snapshots every clipboard change — any agent, any app, your own Cmd+C — into history slots. Zero cooperation needed; clobbered content is always recoverable.
